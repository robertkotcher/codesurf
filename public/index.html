01 / GET STARTED

Install once. Ask from any agent.

CodeSurf is an npm-installable command-line tool. Any coding agent with shell access can call it; the human gets a separate, zoomable desktop window.

Requires Node.js 22.12+, npm, and a signed-in Codex CLI. Python repositories need Python 3.10+ with support for their syntax. The desktop viewer needs a graphical session. 

# Install CodeSurf from this site's versioned release.
npm install -g https://codesurf.io/downloads/codesurf-cli-0.1.0.tgz

# If Codex is not already installed and signed in:
npm install -g @openai/codex
codex login

# Open a map for a human to explore.
codesurf /path/to/repo "What happens when a session expires?"

A human signs in to Codex once; agents can reuse that existing login. CodeSurf uses the Codex account for AI investigation—it does not bundle a model or require a separate CodeSurf account. The Electron desktop runtime downloads on first launch.

Release: codesurf-cli-0.1.0.tgz · SHA-256 checksum · MIT license. See the official Codex setup guide for its installation and sign-in options.

02 / AGENT CONTRACT

Let the agent investigate. Let the human see.

Use CodeSurf when explaining a request flow, onboarding someone to a repository, or answering “where does this value go?” Describe the scenario in natural language, including the inputs or branch that matters. 

codesurf "$PWD" \
  "Trace a signed-in request with an expired access token.
   Assume refresh succeeds. Show how the request retries." \
  --out ./artifacts/session-flow.html

03

Learn together

The human follows calls and asks token-level questions, while the agent can use source or official web references to explain.

Contract Behavior
Input A local repository path, a quoted natural-language question, and optional flags. Use --repo for additional roots.
Output A self-contained HTML map and a JSON source snapshot beside it. An explicit --out makes report locations predictable.
Exit status Zero on successful report generation; nonzero on an analysis or invocation error. The desktop process continues after the CLI exits.
Target code Source is parsed and read. The scenario is reasoned about statically, rather than executed or recorded.
03 / HUMAN INTERFACE

Source first. Diagram second.

  • One panel per file. Relevant excerpts are merged in source order. Calls within the same file loop back to their definitions.
  • Folder-shaped context. Nested yellow regions follow real paths, such as src/lib/api. Collapse a folder and its connections attach to the folder itself.
  • Follow a path. Hover a line to illuminate callers and downstream calls. Click to pin the path; press Escape to clear it. Other code and arrows recede.
  • Read further. Expand context above or below, scroll long lines horizontally, toggle wrapping, or drag a panel's corner to make it larger.
  • Ask about any token. Keep multiple question panels near their source. Answers stream with brief progress, and inactive conversations fade rather than disappear.
04 / REFERENCE

A small CLI surface.

codesurf <repository> ["question"] [options]
Option Purpose
--repo <path> Index another repository root. Repeatable; connections still need source evidence.
--out <file.html> Write HTML and a matching JSON snapshot to a chosen location. Default: ~/.codesurf/reports/.
--no-open Generate a portable report without starting the desktop viewer.
--static Skip LLM investigation; choose an entry by keyword matching and follow statically resolved calls.
--entry <file#name> Pin an explicit starting function when needed. Natural-language mode normally infers it.
--depth <0..12> Maximum traversal depth in static mode. Default: 4.
--limit <1..150> Maximum initially selected functions. Default: 36; multiple functions can share one file panel.
--help Print the current command reference.

Omit the question to type it in the desktop window. Set CODESURF_PYTHON to a matching Python interpreter or CODESURF_CODEX to a Codex executable not on PATH.

05 / UNDER THE HOOD

AI selection. Source-backed connections.

Repository AST→Read-only investigation→Validated call graph→Local code map

TypeScript's compiler API resolves JavaScript and TypeScript definitions, imports, aliases, and calls. Python uses an installed interpreter's AST parser to identify functions, imports, lexical scopes, and statically identifiable method calls. The analyzer does not import the target Python application.

A Codex investigation reads source and proposes the entry, functions, relevant lines, assumptions, and omitted branches. CodeSurf checks those identifiers and line bounds, then requires a resolved call path from the entry to every selected function. Folder grouping and graph interactions are deterministic; the LLM does not invent group labels.

Electron hosts the local viewer. Token questions use Codex's streaming app-server protocol with read-only repository access and live web search. Only user-facing answer text and brief activity notifications appear in the interface.

Supported files include .py, .pyi, .pyw, .ts, .tsx, .mts, .cts, .js, .jsx, .mjs, and .cjs. Python grammar follows the selected interpreter; JavaScript/TypeScript parsing uses the bundled TypeScript 6 compiler API. Syntax diagnostics identify unsupported input.

06 / BOUNDARIES

Know what the map can establish.

Is this a runtime trace?

No. It explains static source relationships for a scenario. Conditions may depend on unknown data, and LLM explanations can be wrong. Dynamic dispatch, framework callbacks, and cross-service HTTP or subprocess links may remain unresolved; CodeSurf does not fabricate those edges.

Does my code leave the machine?

The website does not analyze or upload repositories. The installed CLI's AI features send source inspected by the Codex investigator to its model provider, using your Codex account. Static trace generation with --static avoids that AI investigation; live token questions still use the agent and network. Reports contain source and local paths, so treat them as private repository snapshots.

Can I use the report without the app?

Yes. HTML snapshots support browsing, folder collapse, path focus, and code expansion without a server. New AI questions and streamed replies require the desktop viewer. The adjacent JSON records the source evidence and selected functions.

Which operating systems and versions?

The desktop is built on Electron, and the CLI requires Node.js 22.12 or newer. macOS, Windows, and Linux need an appropriate graphical session for the viewer; headless environments can generate reports with --no-open. Python requires 3.10+ and a grammar-compatible interpreter. This is an early release; automated checks cover language resolution and viewer interactions rather than every OS combination.
