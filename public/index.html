CodeSurf

For Humans

CodeSurf turns your coding agent’s explanation into an interactive code tour with a consistent UI, packaged as an HTML file you can open locally.

Add this sentence to your AGENTS.md, then ask your agent to surf code.

When I ask you to “surf code” or “run CodeSurf,” read and follow the instructions at https://codesurf.io/llms.txt.

Your agent investigates the repository, writes a tour JSON file, and packages it with the official viewer. Source code is processed locally, and the resulting HTML works offline.

Build a tour locally

The packager needs Node.js 20.19 or newer. Download it once, then generate a sample tour.

curl -fsS https://codesurf.io/releases/1.0.0/codesurf.mjs -o codesurf.mjs
node codesurf.mjs --example > demo.json
node codesurf.mjs demo.json --out demo.html

Open demo.html in your browser. To explain your own code, have your agent author a tour and run node codesurf.mjs tour.json --out tour.html.

Back and Next guide the tour. Sidebar links highlight the source they describe. Expand folded code, pan the canvas, or use Fit to see the revealed flow.
