CodeSurf

0.1.0

A CLI that turns a repository and a natural-language question into an interactive code graph.

Python · TypeScript · JavaScript / Node.js

Install

Requires Node.js 22.12+ and a desktop session. Python projects also need a Python 3.10+ interpreter that supports their syntax.

npm install -g https://codesurf.io/downloads/codesurf-cli-0.1.0.tgz

# Required for AI analysis, if not already set up
npm install -g @openai/codex
codex login
Download packageSHA-256

Usage

codesurf /path/to/repo "What happens when a session expires?"

Opens a zoomable desktop graph with source code and call paths. Each file has one panel; selected functions are shown in full.

  • Hover or pin a line to follow downstream calls.
  • Collapse folders, resize files, and toggle line wrapping.
  • Click a token to ask a question using repository context and web lookup.

Calling from an agent

Any agent with shell access can invoke the CLI. Include the inputs and branch you want to explain.

codesurf "$PWD" \
  "Trace a request with an expired token. Assume refresh succeeds." \
  --out ./artifacts/session-flow.html

Writes an HTML map and a JSON source snapshot. Add --no-open on a headless machine. Exit status is zero on successful report generation.

Options

FlagPurpose
--repo <path>Add a repository; repeatable
--entry <file#function>Set the starting function
--depth <0–12>Call depth; default 4
--limit <1–150>Maximum functions; default 36
--out <file.html>Report destination
--no-openGenerate without opening a window
--staticUse offline symbol matching instead of AI

How it works

TypeScript compiler APIs and Python AST parsing index definitions and calls. The Codex CLI selects source relevant to your question. Electron displays the resulting graph.

Analysis is static and can miss dynamic dispatch or runtime behavior. AI analysis sends selected source to your configured model provider. Reports contain source code; review them before sharing.
