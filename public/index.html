CodeSurf

For Humans

CodeSurf gives your coding agent instructions for creating interactive walkthroughs of a codebase or pull request.

Add this sentence to your AGENTS.md.

When I ask you to “surf code” or “run CodeSurf,” read and follow the instructions at https://codesurf.io/llms.txt.

Examples

Once you’ve added the instruction to AGENTS.md, try one of these prompts with your coding agent. CodeSurf produces an interactive HTML walkthrough you can open locally.

Understand a feature

Surf code and show me how sign-in works.

Follow sign-in from its entry point through the code that checks credentials and handles success or failure.

Review a pull request

Run CodeSurf on PR #42 and walk me through the fix.

See the original behavior, the exact lines the PR changes, and how those changes fix the problem.

Trace an error

Surf code and trace what happens when this background job fails.

See where the error is raised, what catches it, and whether the job retries or stops.
