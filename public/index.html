CodeSurf

For Humans

CodeSurf gives your coding agent instructions for creating interactive walkthroughs of a codebase or pull request.

Add this sentence to your AGENTS.md.

When I ask you to “surf code” or “run CodeSurf,” read and follow the instructions at https://codesurf.io/llms.txt.

Examples

  • Surf code and show me how sign-in works.
  • Run CodeSurf on PR #42 and walk me through the fix.
  • Surf code and trace what happens when this background job fails.
