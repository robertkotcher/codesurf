CodeSurf

Ask your coding agent how something in your code works. CodeSurf shows you the answer as the real source, step by step, in your browser.

Get started

Paste this into Claude Code, Codex or any coding agent that can run commands:

Set up CodeSurf by following https://codesurf.io/llms.txt

Then ask it something like:

Surf this repo: what happens when a user's session expires?

What you can do

  • Read the answer first. The direct answer sits at the top, and the steps show the code behind it, one idea at a time.
  • Follow real code. Every card is your actual source, read from disk, with one card per file. Arrows connect the exact lines that call each other, and CodeSurf checks every line before you see it.
  • Explore beyond the tour. Hover any name to see its type. Click it to open where it's defined, even in another file.
  • Ask follow-up questions. Ask in the viewer and a read-only agent answers from your repository, drawing a new view when a picture helps.
  • See the app, too. When a flow starts with a click or a form, your agent runs the app with demo data and circles what was used.
  • Jump around. The timeline lets you go back to any step, or see just the code a few steps talk about, diff style.

Install it yourself

You need Node.js 22.12 or newer. Google Chrome is used for app screenshots, and the Claude Code CLI answers follow-up questions.

npm install -g https://codesurf.io/downloads/codesurf-latest.tgz
codesurf setup
codesurf example

codesurf setup teaches Claude Code the workflow. For other agents, add this line to your AGENTS.md:

When I ask you to "surf" code or explain code visually, run `codesurf guide` and follow it.

Privacy

CodeSurf runs on your computer. The viewer is served from 127.0.0.1, tours are saved in ~/.codesurf, and your code is never uploaded by CodeSurf. Your coding agent and the follow-up agent send what they read to their own model provider, just as they do when you chat with them.
