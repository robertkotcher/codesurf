Getting started

Run CodeSurf from your terminal or ask your coding agent to run it.

# Explore a flow in your repository
codesurf ./my-app "What happens when a user signs in?"

# Try the bundled example without AI setup
codesurf --demo

Options

--repo <path>Add another repository
--entry <file#function>Choose the starting function
--depth <0–12>Call depth; default 4
--limit <1–150>Maximum functions; default 36
--languages <ids>typescript,python,ruby
--staticOffline analysis without AI
--html-onlyExport a report instead of opening the app
--out <file.html>Export destination; requires --html-only
--helpShow all command options
